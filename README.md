# Fashion Diffusion

Proof of concept for **virtual try-on**: given a person image and a garment, generate a realistic image of that person wearing the garment.

Dataset: [HR-VITON](https://github.com/sangyun884/HR-VITON) (person, cloth, masks, pose, parsing, DensePose, and related modalities).

## Scope

This is an experimental PoC. Prioritize clarity and iteration speed over production hardening. See `.cursor/rules/` for coding conventions used in this repo.
